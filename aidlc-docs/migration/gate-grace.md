# Gate Grace Period: ByoriDB Studio

- **작성일**: 2026-05-21
- **전략**: 적극적 도입 (솔로 개발, 전체 대상)

> Grace period = "기존 코드에 즉시 강제하지 않고 유예하는 기간"을 명시한 문서.
> reviewer agent가 PR 검사 시 이 파일을 참조하여 grace 여부를 반영.

## Reviewer 참조 규칙

PR 검사 시 다음 순서로 판단:

1. **즉시 차단 게이트** — grace 없이 항상 적용. 위반 시 PR 블록.
2. **마일스톤 기반 게이트** — 해당 마일스톤 완료 여부 확인 후 적용.
3. **건드린 파일만 적용** — 수정하지 않은 기존 파일에는 적용 안 함.
4. **tech-debt.md 등록 항목** — 기존 빚으로 등록된 패턴은 grace. 새로 같은 패턴을 도입하는 것은 차단.
