# Component Inventory

This is a single-package application repository — there are no separate publishable packages, no infrastructure-as-code packages, and no shared libraries within this workspace. The "components" listed below are the logical modules and UI components inside the single `byoridb-studio` package.

For per-component business and technical responsibilities, see `business-overview.md` and `architecture.md`. This file is the at-a-glance index.

## Application Packages

| Package | Type | Path | Purpose |
|---------|------|------|---------|
| `byoridb-studio` (npm) | Frontend application | `package.json`, `src/` | React 19 + TypeScript UI rendered in the Tauri WebView. |
| `byoridb-studio` (Cargo) | Backend application | `src-tauri/Cargo.toml`, `src-tauri/src/` | Rust + Tauri 2 process; owns the HTTP client and command façade. |

These two share the same product name and version (`0.1.0`) and ship together as a single desktop binary.

## Frontend Modules (`src/`)

| Module | File | Type | Purpose |
|--------|------|------|---------|
| Entry | `src/main.tsx` | Bootstrap | Mounts `<App/>` under `<React.StrictMode>` at `#root`. |
| Root component | `src/App.tsx` | UI orchestrator | Connection lifecycle, health-poll, query orchestration. |
| Connection modal | `src/components/ConnectionModal.tsx` | UI | Initial-connect modal. |
| Server settings | `src/components/ServerSettings.tsx` | UI + helpers | Saved-profile CRUD, reachability test; exports `loadSavedConnections`, `saveSavedConnections`, types. |
| Sidebar | `src/components/Sidebar.tsx` | UI | Schema browser (spaces/tags/edges) with lazy `DESCRIBE` cache; hosts the Settings tab. |
| Query editor | `src/components/QueryEditor.tsx` | UI | nGQL textarea editor with sample queries, ⌘↵ execute, ⌘↑/⌘↓ history. |
| Result panel | `src/components/ResultPanel.tsx` | UI | Table / JSON / Graph view of the latest result. Exports `formatValue`. |

## Frontend Styling (`src/styles/`)

## Backend Modules (`src-tauri/src/`)

| Module | File | Purpose |
|--------|------|---------|
| Process bootstrap + commands | `src-tauri/src/main.rs` | Tauri builder, `AppState`, command registrations, `TauriError`, tracing setup. |

| Build script | `src-tauri/build.rs` | One-line `tauri_build::build()` invocation. |

## Infrastructure Packages

**None.** This repository contains no CDK, Terraform, CloudFormation, Kubernetes manifests, or deployment scripts. The deliverable is a desktop installer produced by `tauri build`.

## Shared Packages

**None.** The studio depends on the external `byoridb` repository at `../byoridb` (server side; not part of this workspace). There is no shared library extracted from this repo.
